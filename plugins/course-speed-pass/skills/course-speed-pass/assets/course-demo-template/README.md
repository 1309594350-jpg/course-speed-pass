# 知行实验室：课程与答题自动化教学 Demo

这是一个完全本地运行的教学沙盒，用来学习网页状态、自动切换流程、JSON/CSV 题库导入、题目匹配、置信度复核、可控任务队列、人工 AI 辅助和 Playwright 端到端测试。

它不需要登录，不会连接学习通或其他网课平台，也不会读取账号、Cookie、真实课程或提交任何学习记录。页面里的题目、答案和评分都是本地模拟数据。

## 最简单的运行方式（macOS）

1. 双击 `启动演示.command`。
2. 浏览器会打开 `http://127.0.0.1:4173`。
3. 点击“从头运行自动演示”，观察六节模拟课程自动完成。
4. 在“智能答题实验室”点击“自动填答”，确认低置信度答案后再“模拟提交”。
5. 如需自定义题库，在“本地题库管理”中选择 JSON 或 CSV 文件。
6. 如需 AI 辅助，生成提示词后手动打开 DeepSeek，并把 JSON 结果粘贴回来复核。
7. 在“本地脚本运行台”选择配置档、范围和预演模式，再测试开始、暂停、继续或停止。
8. 关闭终端窗口即可停止本地服务器。

页面演示本身不需要安装任何依赖。只有第一次运行自动化测试时，才会安装 Playwright 和测试用 Chromium；双击测试脚本会优先使用国内镜像下载。

## 自动化测试

双击 `运行自动化测试.command`，脚本会：

1. 启动本地模拟课程。
2. 使用 Playwright 打开页面。
3. 将演示速度调整为 8 倍。
4. 运行自动播放和章节切换。
5. 断言课程最终结果为 `6/6`、`100%`。
6. 自动填答六道本地题目，并断言默认阈值拦截一条低置信度答案。
7. 确认复核后模拟提交，断言答题结果为 `6/6`、`100 分`。
8. 故意改错一题，断言得分为 `83`，再通过错题重试恢复到 `100`。
9. 验证本地 JSON 报告可以正常下载。
10. 导入 JSON 题库，验证新增、重复、拒绝统计以及 `7/7` 模拟评分。
11. 验证 CSV 替换、题库导出和恢复内置题库。
12. 验证 DeepSeek 手动复核提示词和 JSON 回填，但不访问外部网页。
13. 验证运行台预演不写答案、暂停/继续、停止、快速队列、有限重试和设置导入导出。
14. 验证本地动态题卡检测。
15. 把截图保存到 `artifacts/automation-success.png`、`artifacts/ai-review-success.png` 和 `artifacts/userscript-console-success.png`。

## 答题实验功能

- 题型：单选、多选、判断、填空。
- 策略：题目指纹缓存 → 本地题库 → 明确规则。
- 安全阀：可调置信度阈值，低置信度答案默认要求人工复核。
- 模式：仅填答或复核后模拟提交。
- 辅助：答案来源、命中缓存、错题重试、解析反馈和 JSON 报告导出。
- 题库：JSON/CSV 导入、格式校验、字母答案转换、指纹去重、合并/替换、导出与恢复。
- AI 复核：生成并复制提示词、手动打开官方 DeepSeek、粘贴 JSON 结果、保留来源和置信度。

## 本地脚本运行台

- 配置档：均衡、谨慎、快速和自定义。
- 作用范围：全部、未作答、错题。
- 调度：可选延迟和最多两次有限重试，避免无限循环。
- 控制：开始、暂停、继续、停止；任务状态和进度全程可见。
- 预演：只验证匹配和队列，不写入答案。
- 配置：保存在浏览器本机，可导出 JSON，也可导入恢复。
- 动态页面：使用 `MutationObserver` 统计本地新增或移除的题卡。

这些是借鉴用户脚本的通用交互模式，但运行范围限定在本地 Demo。程序不会访问真实学习平台，不包含真实站点选择器、Cookie/登录态读取、跨站请求、自动提交或反检测逻辑。

DeepSeek 页面不会被程序控制：不读取登录信息，不自动输入问题，不抓取回答，也不连接真实课程。官方网页入口会以普通链接打开，查询和复制由用户手动完成。

JSON 题库可以直接使用数组，也可以写成 `{ "questions": [...] }`。CSV 表头为：

```text
type,prompt,options,answer,aliases,explanation,confidence
```

`options`、多选 `answer` 和 `aliases` 的多个值使用 `|` 分隔。页面中的“下载格式示例”会生成可直接修改的 JSON 文件。

也可以在终端运行：

```bash
npm install
PLAYWRIGHT_DOWNLOAD_HOST="https://npmmirror.com/mirrors/playwright" npx playwright install chromium
npm run automation
```

## 项目结构

```text
知行合一/
├── index.html                 # 模拟网课页面
├── styles.css                # 界面样式与响应式布局
├── src/app.js                # 课程状态机、题库导入、本地答题引擎与任务队列
├── scripts/server.mjs        # 只监听本机的静态服务器
├── automation/runner.mjs     # Playwright 外部自动化测试
├── artifacts/                # 自动化截图输出目录
├── 启动演示.command           # 双击启动页面
└── 运行自动化测试.command      # 双击执行完整测试
```

## GitHub 组件

自动化部分采用 [Microsoft Playwright](https://github.com/microsoft/playwright)，许可证为 Apache-2.0。页面主体没有使用第三方框架，便于直接阅读和修改。

## 学习建议

先在页面中手动播放、暂停、切换章节；再调整答题模式和置信度阈值；然后阅读 `src/app.js` 理解课程状态与答案决策；最后阅读 `automation/runner.mjs`，看浏览器外部脚本如何点击、等待、复核和断言。
